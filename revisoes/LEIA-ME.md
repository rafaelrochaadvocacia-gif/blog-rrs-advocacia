# revisoes/

Gerado pelas rotinas do blog (ver `rotinas/redator.md` e `diretrizes/revisao-automatica.md`).

| Arquivo | O que é |
|---|---|
| `<slug>.md` | Texto do artigo como a rotina escreveu |
| `<slug>.fontes.json` | Fontes oficiais conferidas para cada citação jurídica |
| `<slug>.variacao.json` | Ficha de variação (abertura, simulação, Box, chamada) |
| `<slug>.revisao.json` | Parecer do revisor automático (inclui o postId do Wix) |
| `<slug>.rascunho.md` | Snapshot do rascunho entregue no Wix |
| `<slug>.publicado.md` | Snapshot do post depois de publicado pelo Rafael |
| `<slug>.diff.md` | O que mudou entre rascunho e publicado (as rotinas aprendem com isto) |
| `calibracao.csv` | Histórico da calibração (Fase 1 → Fase 2) |
